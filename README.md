### 音声を解析して音程を視覚化するツールですわ～(⋈◍＞◡＜◍)。✧♡

* Geminiたんがほぼ全て作ってくれましたわ～！
* １ファイルに、CSS,JSが全て詰まってますわ～！
* 外部ライブラリ使ってませんわ～！１ファイル完結ですわ～！
* PC用ですわ～（iPhoneでも少し使えるかもですわ～）
* 許可したマイクの音声を拾ってリアルタイムで音程を解析しますわー
 （低音、高音はカットしてますわ～）
* 試験機能：MIDI録音できますわ～（精度・加工は雑ですわ～）

* 「START」でマイクを聞かれるので、選択して許可してくださいませ～

<img width="800" height="600" alt="スクリーンショット 2026-06-02 220931" src="https://github.com/user-attachments/assets/e6bb7e61-76e4-4ef5-b0e2-e80f1311c984" />

* 鍵盤を押すと、音が出ますわ～（自分の声の音程と比較して下さいませ～）
* 「REC」ボタンでMIDI録音できますわ～（精度は雑ですわ～）
* 「STOP」ボタンで録音終了ですわ～
* 録音を止めると、「MIDI」ダウンロードボタンが表示され、MIDIデータファイルをDownloadできますわ～
#### 「MIDI EXPORT OPTION」
* テンポ設定：解析する時のテンポを指定できますわ～。精度が上がるかもですわ～
* CH2 解析最小音符（クオンタイズ単位）なるべく指定した音符にしますわ～
#### MIDIデータファイルの構成
* CH1：MIDI生データが入っていますわ～。すごく細かいですわ～
* CH2：生データは細かすぎるので、適当に結合して音符を減らしてますわ~
