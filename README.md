### 音声を解析して音程を視覚化するツールですわ～(⋈◍＞◡＜◍)。✧♡
<img width="347" height="379" alt="スクリーンショット 2026-06-03 091819" src="https://github.com/user-attachments/assets/75388326-bfe7-46ba-b8ae-f14d48150cea" />
* Geminiたんがほぼ全て作ってくれましたわ～！
* １ファイルに、CSS,JSが全て詰まってますわ～！
* 外部ライブラリ使ってませんわ～！１ファイル完結ですわ～！
* PC用ですわ～（iPhoneでも少し使えるかもですわ～）
* 許可したマイクの音声を拾ってリアルタイムで音程を解析しますわー
 （低音、高音はカットしてますわ～）
* 実験でMIDI録音できますわ～（精度は雑ですわ～）

<img width="800" height="600" alt="スクリーンショット 2026-06-02 221011" src="https://github.com/user-attachments/assets/65759294-2b73-49cd-9add-09f334141446" />
* 「START」でマイクを聞かれるので、選択して許可してくださいませ～
* 鍵盤を押すと、音が出ますわ～（自分の声の音程と比較して下さいませ～）
* 「Rec」ボタンででMIDI録音できますわ～（精度は雑ですわ～）
* 録音を止めると、「MIDI」ダウンロードボタンで、MIDIデータファイルをDownloadできますわ～

#### 設定画面
<img width="800" height="600" alt="スクリーンショット 2026-06-02 220931" src="https://github.com/user-attachments/assets/e6bb7e61-76e4-4ef5-b0e2-e80f1311c984" />
* 背景色：OBS用に透過用（緑・青）に変更できますわ~
* 鍵盤の透明度：その名の通り、透明度を変更できますわ~
* 音色：鍵盤の音色を変更できますわ~
* 鍵盤の音量：音量を変更できますわ~
* マイク・ループバックの音量：自分の声を聴くことができますわ~（どＭ機能ですわ~）
* 時間差（ディレイ）：自分の声を時間差で聴くことができますわ~（ダメージ大きいですわ~）
